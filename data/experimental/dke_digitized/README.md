# Digitized historical DKE reference data

These CSVs were copied without numerical alteration from the public
`hdimsey/Briggs-Rauscher-Data` repository on 2026-09-20.

- `iodide_time_trace.csv`: iodide pI versus time reconstructed from Figure 4.5 of
  Epstein and Pojman, *An Introduction to Nonlinear Chemical Dynamics*.
- `iodide_iodine_limit_cycle.csv`: iodine versus iodide pI reconstructed from the
  same figure.

The upstream README states that the original experimental data are no longer
available and that WebPlotDigitizer was used. These files therefore support a
historical reproduction check, not parameter estimation with known uncertainty.

Sources:

- https://github.com/hdimsey/Briggs-Rauscher-Data
- https://raw.githubusercontent.com/hdimsey/Briggs-Rauscher-Data/main/IodideOscillationDataDKE.csv
